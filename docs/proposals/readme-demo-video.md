# Proposal: a 20-second recording at the top of the README

**Why.** Many reviewers read the README and never open the site. Matinee's
best moments move: countdowns ticking, the poster morphing into the show
page, the District map's live halos. Stills don't show any of that.

**What.** A scripted, reproducible phone-width recording with Playwright's
video capture: Discover, then Rush with countdowns running, a show page,
the District map. Trim to about 20 seconds, encode as MP4 (with a GIF
fallback) under 3 MB, and put it above the screenshots. The same clip works
on the personal site and in a portfolio deck. Re-run the script after a
redesign or data refresh.

**Size.** 2 to 3 hours.

**Needs from Charlie.** Whether third-party poster art in a video is fine
(it is the same open question as the posters in the repo).
